# Evolution Agent

## Description
The Evolution Agent studies evolutionary relationships between animal species by comparing their protein sequences and identifying biologically meaningful similarities. It groups species according to molecular characteristics and reconstructs evolutionary patterns to help explain species divergence, common ancestry, and adaptation.

## Objective
- Compare species at the molecular level.
- Identify genetically and functionally related species.
- Discover groups of species sharing evolutionary characteristics.
- Build evolutionary trees and similarity networks.
- Explain how species diverged and adapted over time.

## Approach
Unlike traditional taxonomy, this agent uses protein foundation models and clustering techniques to infer relationships directly from biological data.
