`worker_node._context_for(agent_name, context)` (`worker_node.py:72-107`):

1. If no `recognition_image_id` is present, the context passes through untouched.
2. Otherwise the id key is stripped from a copy (`trimmed`).

### 5.10 Error handling and privacy protections

- **17 error codes** in `domain/errors.py`: paired-input contract (4), image
  transport (4), image content (5), classification (3), taxonomy (1).
- `RecognitionError.__init__` (`errors.py:97`) takes **an `ErrorCode` and nothing
  else**; the message is derived from the code alone, so two requests failing the
  same way produce byte-identical text. `Exception.args` can hold only the fixed
  message.
- Nodes never raise: a `RecognitionError` is written into state as `error_code`
  and the router jumps to `finalize`.
- `api.py` never returns HTTP 500: `execute` wraps `_agent.run` in a bare
  `except Exception` (`api.py:90`) and returns the shared schema with
  `INTERNAL_ERROR_CODE` (`:36`) and a fixed, data-free `INTERNAL_ERROR_MESSAGE`
  (`:41`) — *"Deliberately not an HTTPException"* (`:106`). A `uuid.uuid4().hex`
  correlation id (`:99`) links caller and log without putting anything about the
  failure into the response.
- `quiet_dependency_http_loggers()` (`api.py:65`) is invoked at import (`:76`),
  pinning `httpx`, `httpcore`, `urllib3` and `openai` to `WARNING`.
- Image data is excluded **by construction**: `domain/models.py:66` and `:70`
  declare `image_bytes` and `context` as `Field(repr=False, exclude=True)`, under
  `model_config = ConfigDict(extra="forbid", frozen=True)` (`:60`).
- `config.py` loads no `.env` file, by design.
- `.env.example` is committed with **names and empty placeholders only** — 28
  variable names, no `LANGSMITH_*` or `LANGCHAIN_*` entry (0 matches).
- The agent `.env` is **untracked**, confirmed by `git ls-files --error-unmatch`.
