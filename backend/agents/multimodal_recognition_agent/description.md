# Multimodal Species Recognition Agent

## Description
The Multimodal Species Recognition Agent identifies animal species from images and enriches the prediction with genomic, evolutionary, ecological, and conservation knowledge by collaborating with the other specialized agents.

## Objective
Bridge computer vision and biological knowledge by allowing users to upload animal images and instantly retrieve comprehensive scientific information through the platform's multi-agent ecosystem.

## Problem Addressed
Identifying an animal from an image is relatively easy with modern AI models, but obtaining reliable biological information about that species usually requires searching multiple databases such as NCBI, GBIF, IUCN, and PubMed.

## Main Tasks
- Identify the species in an image.
- Estimate prediction confidence.
- Query other specialized agents for follow-up knowledge.
- Present genomic, evolutionary, ecological, and conservation context in one place.
