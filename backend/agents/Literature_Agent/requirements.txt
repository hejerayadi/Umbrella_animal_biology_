# --- Embeddings & retrieval (subagents/publication_support/, ---------------
#     subagents/retrieval_knowledge/) - required, do not remove.
# `embeddings/embedder.py` and `retrieval_knowledge/finalagenttt.py` both load a
# sentence-transformers model. Both build it lazily, so nothing is downloaded
# until a journal recommendation or a semantic search actually runs - but the
# package itself must be installed or those imports fail at agent start.
#
# This pulls torch (~2GB on Windows CPU wheels). It is the single heaviest
# dependency in the repo; the two subagents that need it are the reason.
sentence-transformers==3.3.1

# TF-IDF fallback ranking in retrieval_knowledge/finalagenttt.py.

# Used directly by ranking/ranker.py and the retrieval subagent. Already an

# it is imported inside the function, so it stays a soft dependency, but it
# is pinned here so a normal install gets the correction step.
